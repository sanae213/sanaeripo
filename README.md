# 商品力診断ツール

中小企業向けのシンプルなWebアプリです。入力フォームの内容をもとに、AIが「商品力診断レポート」を生成します。

## 使い方

1. ローカルサーバーを起動します。
   ```bash
   python3 -m http.server 8000
   ```
2. ブラウザで `http://localhost:8000` を開きます。
3. OpenAI APIキーを入力します。
4. 分析プロンプト（あなたの診断プロンプト）を設定します。
5. フォームを入力して「AIで分析する」を押します。

## 入力項目

- 会社名
- 商品名
- 商品説明
- ターゲット
- 悩み
- 競合
- 強み
- 価格
- 販売方法

## 注意

- APIキーはブラウザ上でのみ利用され、保存はしていません。
- API利用料はOpenAIの契約内容に従って課金されます。
